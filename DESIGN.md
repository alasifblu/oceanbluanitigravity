# DESIGN.md — OceanBlu Sovereign Design System

This design specification defines the visual language, design tokens, typography, and component layouts for **OceanBlu Ltd.** (`oceanblu.digital`), calibrated for Google Stitch (`stitch.withgoogle.com`) and production Next.js engineering.

---

## 1. Visual Philosophy: Sovereign Precision

- **Tone & Feeling:** High-conviction, enterprise-grade, authoritative, and deep-tech. Modeled after Stripe, Linear, and Palantir, paired with luxury hardware presentation.
- **Core Visual Motif:** Sovereign neural hardware appliances running in private local networks—dark obsidian depths illuminated by electric cobalt precision glows, high-contrast cyber lime action triggers, and glowing telemetry indicators.
- **Anti-Fragmentation Rule:** Sections must never look like disconnected rectangular boxes stacked on top of each other. Every section flows seamlessly into the next via continuous radial ambient glows, unified typography scales, and shared glassmorphism depth.

---

## 2. Color Palette & Design Tokens

### 2.1 Surfaces & Canvas
- **Obsidian Canvas:** `#05070E` (Deep space base)
- **Surface Layer 1:** `#0A0E1A` (Card base with 75% opacity and 16px blur)
- **Surface Layer 2 (Elevated):** `#10172A` (Active card / hover state with 14px blur)
- **Glass Borders:** `rgba(255, 255, 255, 0.08)` (Subtle translucent hairline border)
- **Glass Borders (Active/Hover):** `rgba(0, 102, 255, 0.4)` to `rgba(255, 255, 255, 0.22)`

### 2.2 Accents & Brand Signals
- **Precision Cobalt Blue:** `#0066FF` (Primary technology glow, system status, active tab indicators)
- **Cobalt Glow:** `rgba(0, 102, 255, 0.35)` (Radial ambient backlighting)
- **Cyber Neon Lime:** `#D4FF00` (High-conversion primary CTA button, 100% data sovereignty bento highlight)
- **Radiant Warm Flame:** `#FF5500` (Operational highlight, hardware heat fin alerts)
- **Emerald Pulse:** `#10B981` (Live air-gap status indicators)

### 2.3 Typography Scale
- **Primary Display Sans:** Inter / Plus Jakarta Sans / Geist Sans (Bold 700 / Black 900)
- **Editorial Serif Accent:** Playfair Display / Instrument Serif / Serif Italic (used selectively on key emphasis words, e.g. *"Delivered in a Box"*, *"private, faster, and deterministic"*)
- **Telemetry & Technical Monospace:** JetBrains Mono / Geist Mono (for system specs, latencies, parameter counts, and packet egress)
